## 1. 빛을 숫자로 다루기

- **입체각(solid angle)**: 3차원에서의 "각도". 단위 구 위에서 방향들이 차지하는 면적이며 단위는 sr(스테라디안). 반구 전체는 2π sr.
- **방사 휘도(radiance) L**: 한 점에서 한 방향으로 나가는 빛의 세기(단위 면적·단위 입체각당 일률). 카메라 픽셀 값은 결국 그 방향으로 들어오는 radiance다.
- **방사 조도(irradiance) E**: 한 점에 모든 방향에서 들어오는 빛을 코사인 가중으로 더한 값.

```text
E = ∫_Ω L_i(ω) · cosθ dω
```

`cosθ`가 붙는 이유: 비스듬히 들어오는 빛은 같은 양이라도 더 넓은 면적에 퍼지기 때문이다(Lambert의 코사인 법칙).
radiance는 빈 공간에서 레이를 따라 변하지 않는다. 그래서 "레이를 쏴서 맞은 곳의 radiance를 읽는다"는 계산이 성립한다.

## 2. 렌더링 방정식

한 점 `x`에서 방향 `ωo`로 나가는 빛:

```text
L_o(x, ωo) = L_e(x, ωo) + ∫_Ω f(x, ωo, ωi) · L_i(x, ωi) · cosθi dωi
```

| 항 | 의미 |
| --- | --- |
| `L_e` | 표면이 스스로 내는 빛(광원) |
| `f` | BSDF: 들어온 빛 중 `ωo`로 반사·투과되는 비율. 재질 그 자체 |
| `L_i(x, ωi)` | `ωi` 방향에서 들어오는 빛 = 그 방향으로 레이를 쐈을 때 맞는 점의 `L_o` |
| `cosθi` | 입사 각도에 따른 감쇠 |

핵심은 **`L_i`가 다른 점의 `L_o`라는 재귀 구조**다. 빛이 여러 번 튕기는 간접광이 이 재귀에서 나온다.
이 적분은 해석적으로 풀 수 없어서 무작위 표본으로 추정한다.

## 3. 몬테카를로 적분

함수 `g`의 적분을, 확률 밀도 `p`로 뽑은 표본 `X`로 추정한다:

```text
∫ g(x) dx  ≈  (1/N) Σ g(X_k) / p(X_k)
```

- 이 추정값의 **기대값은 정확히 적분값**이다(불편 추정, unbiased). 조건: `g ≠ 0`인 곳에서 `p > 0`.
- 표본을 늘리면 오차(표준편차)가 `1/√N`로 줄어든다. 노이즈를 절반으로 줄이려면 샘플이 4배 필요하다.
- **분산(variance)** = 노이즈의 크기. **편향(bias)** = 샘플을 무한히 늘려도 남는 오차. Path tracer 디버깅은 이 둘을 구분하는 일이다.

## 4. 경로 추적 알고리즘

렌더링 방정식의 재귀를 "방향 하나만 뽑아 계속 따라가기"로 바꾼 것이 경로 추적이다.

```text
L = 0, β = 1                       # β: 처리량(throughput), 지금까지 경로가 깎인 비율
ray = 카메라 레이
for depth in 0..max_depth:
    hit = 장면과 교차
    if 맞지 않음: L += β · 환경광(ray.dir); break
    L += β · L_e(hit)               # 광원에 맞으면 기여
    (ωi, f, pdf) = BSDF에서 방향 샘플링
    β *= f · cosθi / pdf
    러시안 룰렛
    ray = (hit.p, ωi)
```

- 재귀 대신 반복문과 `β`를 쓰면 GPU에서 스택 없이 구현할 수 있다.
- **러시안 룰렛**: 경로를 확률 `q`로 살리고 살아남으면 `β /= q`. 기대값은 그대로라 편향이 없고, 기여가 작은 경로를 일찍 끝낼 수 있다.
- **누적**: 프레임마다 픽셀당 경로를 하나 더 추적해 평균에 더한다. 평균이 곧 몬테카를로 추정값이다.

## 5. 중요도 샘플링과 Lambert

`p`가 적분할 함수 모양과 비슷할수록 분산이 작다. 극단적으로 `p ∝ g`이면 분산은 0이다.

Lambert(완전 확산) BSDF는 `f = albedo / π`로 방향과 무관하다. 그러면 적분할 함수는 `cosθ`에 비례하므로
**코사인 가중 반구 샘플링** `p(ω) = cosθ / π`를 쓴다.

```text
β *= f · cosθ / p = (albedo/π) · cosθ / (cosθ/π) = albedo
```

계산이 albedo 곱셈 하나로 줄어든다. 생성 방법: 단위 원판에서 균등하게 점을 뽑아 반구 위로 올린다(Malley 방법).

**균등 반구 샘플링과 비교하기**: `p = 1/(2π)`로도 같은 평균에 수렴하지만 노이즈가 더 크다. 이것이 "같은 정답, 다른 분산"의 첫 실험이다.

## 6. 광원 직접 샘플링 (NEE)

작은 광원은 BSDF 방향 샘플링으로 맞히기 어렵다. 그래서 정점마다 **광원 위의 점을 직접 하나 뽑아** 그림자 레이로 보이는지 확인한다(Next Event Estimation).

```text
직접광 ≈ f(ωo, ωi) · L_e · cosθ_surface / pdf_ω
```

- 광원은 면적으로 샘플링하므로 pdf를 **입체각 측도로 변환**해야 한다:

```text
pdf_ω = pdf_A · dist² / |cosθ_light|
```

  멀리 있거나 비스듬한 광원일수록 작은 입체각을 차지한다는 뜻이다. 이 변환을 빠뜨리는 것이 가장 흔한 편향 버그다.
- 구 광원은 표면 균등 대신 **보이는 원뿔 안에서 방향을 균등 샘플링**하면 뒷면 낭비가 없다.
- NEE를 쓰면 BSDF 샘플링으로 광원에 맞은 기여는 **중복이므로 빼야** 한다(8장의 MIS가 둘을 섞는 방법).
- 거울·유리처럼 델타 BSDF는 특정 방향으로만 반사하므로 무작위 광원 점과 연결할 수 없다. 이 정점에서는 NEE를 생략한다.

## 7. 재질: 거울, 유리, GGX

### 7.1 거울

반사 방향 `ωi = reflect(-ωo, n)` 하나만 가능하다. pdf가 델타 함수라 `β *= F`(반사율)로 처리한다.

### 7.2 매끈한 유리 (유전체)

- **Snell 법칙**: `η_i sinθ_i = η_t sinθ_t`. 굴절 방향 계산.
- **Fresnel**: 반사되는 비율 `F`는 각도에 따라 변한다. 수직이면 약 4%, 스치는 각도일수록 100%에 가까워진다.
- 구현: 확률 `F`로 반사, `1-F`로 굴절을 선택하면 `β`가 바뀌지 않는다(선택 확률과 가중치가 상쇄).
- **전반사**: 굴절각이 존재하지 않으면 반사만 한다.
- 굴절 시 radiance는 `1/η²`만큼 스케일된다. 물체를 들어갔다 나오면 상쇄된다.

### 7.3 GGX 미세면 금속

거친 표면을 "방향이 제각각인 작은 거울들"로 본다.

```text
f = D(h) · F(ωo·h) · G(ωo, ωi) / (4 · cosθo · cosθi)
```

| 항 | 의미 |
| --- | --- |
| `D` | 미세면 법선 분포(GGX). 거칠수록 넓게 퍼짐 |
| `F` | Fresnel. 금속은 Schlick 근사 `F0 + (1-F0)(1-cos)⁵` |
| `G` | 미세면끼리 가리고 그림자 지는 비율(Smith) |
| `h` | 하프 벡터 `normalize(ωo + ωi)` |

- 샘플링은 **보이는 법선 분포(VNDF)** 샘플링이 분산이 가장 작다(Heitz 2018).
- 단일 산란 모델은 거칠수록 **에너지를 잃는다**(미세면 사이 다중 반사를 무시). Furnace test에서 보이는 손실은 버그가 아니라 모델의 한계이며 기록 대상이다.

D3D12 프로젝트의 PBR 셰이더(`PbrCommon.hlsli`)가 같은 D·F·G를 쓴다. 차이는 그쪽은 광원 방향이 정해져 있고, 여기서는 방향을 샘플링한다는 점이다.

## 8. 다중 중요도 샘플링 (MIS)

같은 직접광을 두 가지 방법으로 추정할 수 있다.

| 방법 | 잘 맞는 경우 | 약한 경우 |
| --- | --- | --- |
| BSDF 샘플링 | 매끈한 재질 + 큰 광원 | 거친 재질 + 작은 광원 |
| 광원 샘플링(NEE) | 거친 재질 + 작은 광원 | 매끈한 재질 + 큰 광원 |

MIS는 두 추정을 가중치로 섞어 **각 상황에서 잘하는 쪽을 자동으로 더 믿는다**. power heuristic:

```text
w_light = p_light² / (p_light² + p_bsdf²)
w_bsdf  = p_bsdf²  / (p_light² + p_bsdf²)
```

- 두 pdf는 **같은 측도(입체각)**여야 한다.
- 광원 샘플: `w_light` 계산에 그 방향의 `bsdf_pdf`가 필요하다.
- BSDF 샘플이 광원에 맞았을 때: `w_bsdf` 계산에 그 점의 광원 pdf가 필요하다. 이전 정점의 `bsdf_pdf`를 경로 상태로 넘겨 둔다.
- Veach의 광택 판 장면(4단계 거칠기 판 × 4가지 크기 광원)이 두 방식의 장단점과 MIS 효과를 한 장에 보여준다.

## 9. 환경맵 중요도 샘플링

HDR 환경맵은 태양처럼 작은 영역에 에너지가 몰려 있다. 균등 샘플링으로는 태양을 거의 못 맞혀 노이즈가 심하다.

1. 각 픽셀의 밝기(휘도)에 `sinθ`를 곱해 2D 분포를 만든다. `sinθ`는 등장방형 이미지가 극지방을 늘려 그리는 것을 보정한다.
2. 행 합계로 **marginal CDF**(어느 행인지), 행마다 **conditional CDF**(그 행의 어느 열인지)를 만든다.
3. 난수 두 개로 행 → 열을 이진 탐색해 방향을 고른다.
4. pdf를 입체각으로 변환: `pdf_ω = pdf_uv / (2π² sinθ)`.

이렇게 고른 방향을 NEE 광원 후보로 쓰고 MIS로 BSDF 샘플링과 결합한다.

## 10. 맞게 만들었는지 확인하기

노이즈 이미지는 "그럴듯해 보이는데 틀린" 경우가 많다. 검증은 `docs/VERIFY.md`의 V-ID를 따른다.

- **두 추정기 비교**: BSDF only와 Light only는 노이즈 양은 달라도 **평균이 같아야** 한다. 다르면 적어도 하나에 편향이 있다.
- **White Furnace test**: 모든 방향에서 radiance 1이 들어오는 환경에 반사율 1인 물체를 두면, 에너지 보존 재질은 배경과 구분되지 않아야 한다.
- **수렴률**: 참조 이미지 대비 RMSE를 spp에 대해 log-log로 그리면 기울기가 -0.5여야 한다. 어느 순간 평평해지면 편향이 있다는 신호다.
- **참조 렌더러**: Mitsuba·PBRT로 같은 장면을 렌더링해 비교한다. 단위·색 공간·카메라 규약을 먼저 맞춘다.

## 11. 래스터화와의 관계

D3D12 프로젝트의 Deferred 렌더러는 렌더링 방정식을 다음처럼 근사한다.

| 항목 | 래스터 근사 | Path Tracer |
| --- | --- | --- |
| 직접광 | 방향광 하나, 그림자 없음 | 모든 광원, 그림자 자동 |
| 확산 환경광 | SH 9계수 | 반구 적분 |
| 반사 환경광 | Split-sum(미리 필터한 큐브맵 + BRDF LUT) | 정확한 적분 |
| 간접광 | 없음 | 여러 번 튕김 |

같은 장면을 두 방식으로 렌더링하면 어떤 근사가 어디서 얼마나 다른지 확인할 수 있다. 이것이 Path Tracer를 **기준 이미지**로 쓰는 이유다.
